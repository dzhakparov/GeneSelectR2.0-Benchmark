# Figure manifest

## Scope

The committed figures use the archived 11-dataset figure set:

`GSE101794`, `GSE107994`, `GSE13355`, `GSE65682`, `GSE69683`, `imvigor210`,
`sosall`, `GSE16879`, `GSE91061`, `GSE92415`, and `GSE206285`.

The source tables were generated by complementarity scripts 01 to 04 from
saved benchmark rankings and fits. The seven primary datasets support the
current numerical report. The four follow-up datasets are retained in these
archived figures to preserve the earlier figure appearance and dataset
coverage.

## Rendering

`redesign/complementarity_analysis/06_make_figures.R` renders PDF and 300-dpi
PNG outputs from the source tables. The script writes to the ignored
complementarity result directory when it is run. The committed files are exact
copies of the archived rendered outputs.

The PDF files contain one page each. The PNG files were inspected after
rendering for clipped labels, panel overlap, and dataset-scope errors.
