# Figure manifest

## Scope

The committed figures use these seven manuscript datasets:

`GSE101794`, `GSE107994`, `GSE13355`, `GSE65682`, `GSE69683`, `imvigor210`,
and `sosall`.

The source tables were generated by complementarity scripts 01 to 04 from
saved benchmark rankings and fits. Each source table was checked for the exact
paper dataset set and finite numeric values. The four exploratory datasets
(`GSE16879`, `GSE91061`, `GSE92415`, and `GSE206285`) are excluded.

## Rendering

`generate_paper_figures.R` renders PDF and 300-dpi PNG outputs from the source
tables. The script writes to the ignored complementarity result directory when
it is run. The committed files are the verified paper-scope copies of those
outputs.

The PDF files contain one page each. The PNG files were inspected after
rendering for clipped labels, panel overlap, and dataset-scope errors.
